# 最后防线（Frontline Guardian）

Godot 4.7 的 2D 即时战斗、塔防与 Roguelite 八夜防守 Demo，现加入双英雄成长、装备商店和哥布林营地。全部画面由代码绘制，不依赖外部素材。

## 玩法

- 开局按 `1` 选择狂战士或按 `2` 选择冰霜法师，也可点击英雄卡片。使用**方向键**移动，鼠标左键朝指针方向射击。方向键取代了旧版 WASD，避免 `W` 移动与技能键冲突。
- 战斗中按 `Q/W/E/R` 释放四个职业技能；升级后获得技能点，按 `5/6/7/8` 升级相应技能。左下角显示经验，底部显示技能等级和冷却。狂战士侧重近战击退、战吼和冲锋；冰霜法师侧重远程伤害、范围减速与防护。
- 准备阶段按 `B` 打开商店，点击购买装备或恢复药剂；按 `I` 打开背包，点击背包物品穿戴、点击槽位卸下，按住 Shift 点击背包物品出售。商店和炮塔共用右上角同一金币余额。背包可放 12 件物品，装备有 6 个槽位。当前共有 12 件装备，其中 3 件改变技能范围或伤害。
- 按 `1` 选择速射塔（40 金币），按 `2` 选择重炮塔（55 金币）；绿色预览表示可建造，红色表示位置不合法或金币不足。点击放置，右键取消建造。空手点击炮塔可选中并查看射程、下一级价格与属性；按 `U` 升级、`H` 维修、`X` 出售、`P` 切换攻击优先级。
- 按 `F` 朝移动方向闪避；未按方向键时朝鼠标方向闪避。闪避有短暂无敌和冷却。
- 按空格开始下一夜。每夜清空后按 `Q` 或 `E`，也可以点击卡片，从两项随机强化中选择一项；共有 20 种强化。
- 第 2 夜结束后，在强化选择界面按 `G` 进入哥布林营地；直接选择强化即可跳过。本局只能进入一次。营地中击败小 Boss 并走到掉落物旁领取职业装备，随后返回基地继续选择强化和第 3 夜。按 `Esc` 可撤退，但本局不能重新进入。营地内基地波次与炮塔暂停，生命、经验、金币和装备与基地共用。
- 守住右侧核心并活过八夜即获胜。第 4 夜出现精英事件，第 8 夜出现 Boss。玩家生命耗尽或核心被摧毁即失败。按 `R` 重开。

敌人在道路走廊中动态寻路，建造和摧毁炮塔后会重新规划路线；无法完全封死入口至核心的通道。敌人包括普通、快速、重甲、远程、精英和 Boss。远程敌人与 Boss 攻击前会预警，随后发射可闪避的实体弹丸。击杀敌人获得金币；炮塔按设定优先级自动瞄准。夜次越高，敌人数量、生命和速度越高。

## 运行

使用 Godot 4.7 或同系列稳定版导入 `project.godot`，按 F6/F5 运行。命令行可执行 `godot --headless --path . --editor --quit` 验证导入，再分别运行 `tests/smoke.gd`、`tests/hero_rpg.gd`、`tests/dungeon.gd`、`tests/phase4_full_run.gd`、`tests/playthrough.gd`、`tests/economy.gd` 和 `tests/performance.gd`，例如 `godot --headless --path . --script res://tests/dungeon.gd`。

## 验证边界

冒烟测试检查夜次编排、敌人类型、建造绕路与封路保护、预警弹丸与闪避、炮塔管理和 20 种强化的属性变化。英雄测试检查八个技能的实际伤害、减速、装备词条与三个特殊效果、经验升级及购买失败；副本测试用真实飞行弹丸击败小 Boss、拾取奖励并检查防重、返回后炮塔开火与第 3 夜启动。连贯回归测试从默认金币依次完成两夜、副本和余下六夜，并检查核心被毁的失败判定。八夜通关与经济策略测试均从默认 100 金币开始，只使用实际击杀奖励；脚本会按固定位置自动建塔和选强化，副本测试会自动摆放英雄和瞄准 Boss，不模拟人的移动、操作时机与手感。性能测试测量 headless 战斗逻辑，不代表图形帧率。图形启动与截图可检查渲染器和场景布局，但完整人手操作、技能手感、副本难度与经济平衡仍需试玩。
