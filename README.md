# 最后防线（Frontline Guardian）

Godot 4.7 的 2D 即时战斗、塔防与 Roguelite 八夜防守 Demo。全部画面由代码绘制，不依赖外部素材。

## 玩法

- WASD 移动，鼠标左键朝指针方向射击。
- 按 `1` 选择速射塔（40 金币），按 `2` 选择重炮塔（55 金币）；绿色预览表示可建造，红色表示位置不合法或金币不足。点击放置，右键取消建造。空手点击炮塔可选中并查看射程、下一级价格与属性；按 `U` 升级、`H` 维修、`X` 出售、`P` 切换攻击优先级。
- 按 `F` 朝移动方向闪避；未按方向键时朝鼠标方向闪避。闪避有短暂无敌和冷却。
- 按空格开始下一夜。每夜清空后按 `Q` 或 `E`，也可以点击卡片，从两项随机强化中选择一项；共有 20 种强化。
- 守住右侧核心并活过八夜即获胜。第 4 夜出现精英事件，第 8 夜出现 Boss。玩家生命耗尽或核心被摧毁即失败。按 `R` 重开。

敌人在道路走廊中动态寻路，建造和摧毁炮塔后会重新规划路线；无法完全封死入口至核心的通道。敌人包括普通、快速、重甲、远程、精英和 Boss。远程敌人与 Boss 攻击前会预警，随后发射可闪避的实体弹丸。击杀敌人获得金币；炮塔按设定优先级自动瞄准。夜次越高，敌人数量、生命和速度越高。

## 运行

使用 Godot 4.7 或同系列稳定版导入 `project.godot`，按 F6/F5 运行。命令行可执行 `godot --headless --path . --editor --quit` 验证导入，再分别执行 `godot --headless --path . --script res://tests/smoke.gd`、`godot --headless --path . --script res://tests/playthrough.gd`、`godot --headless --path . --script res://tests/economy.gd` 和 `godot --headless --path . --script res://tests/performance.gd`。

## 验证边界

冒烟测试检查夜次编排、敌人类型、建造绕路与封路保护、预警弹丸与闪避、炮塔管理和 20 种强化的属性变化。八夜通关与经济策略测试均从默认 100 金币开始，只使用实际击杀奖励；脚本会按固定位置自动建塔和选强化，不模拟人的瞄准、移动与操作时机。性能测试测量 headless 战斗逻辑，不代表图形帧率。画面交互、手感和真实玩家平衡仍需图形环境试玩。
