# 前线守护者

Godot 4.7 的 2D 即时战斗、塔防与 Roguelite 三波可玩 Demo。全部画面由代码绘制，不依赖外部素材。

## 玩法

- WASD 移动，鼠标左键朝指针方向射击。
- 按 `1` 选择速射塔（40 金币），按 `2` 选择重炮塔（65 金币）；在道路之外点击放置，右键取消建造。
- 按空格开始下一波。每波清空后按 `Q` 或 `E` 从两项随机强化中选择一项，再按空格继续。
- 守住右侧核心并活过三波即获胜。玩家生命耗尽或核心被摧毁即失败。按 `R` 重开。

敌人沿固定折线道路进攻，会在靠近玩家时攻击玩家，到达终点后攻击核心。击杀敌人获得金币；炮塔自动瞄准。三波敌人数量、生命和速度递增。

## 运行

使用 Godot 4.7 或同系列稳定版导入 `project.godot`，按 F6/F5 运行。命令行可执行 `godot --headless --path . --editor --quit` 验证导入，之后执行 `godot --headless --path . --script res://tests/smoke.gd` 运行逻辑冒烟测试。

## 验证边界

冒烟测试检查波次配置、路径投影、建造位置和强化池。画面交互、输入手感及真实帧率需要图形环境人工验证。
