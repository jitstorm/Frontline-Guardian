# 最后防线（Frontline Guardian）

Godot 4.7 的 2D 即时战斗、塔防与 Roguelite 八夜防守 Demo。全部画面由代码绘制，不依赖外部素材。

## 玩法

- WASD 移动，鼠标左键朝指针方向射击。
- 按 `1` 选择速射塔（40 金币），按 `2` 选择重炮塔（65 金币）；在道路之外点击放置，右键取消建造。空手点击炮塔可选中，按 `U` 升级、`H` 维修、`X` 出售、`P` 切换攻击优先级。
- 按空格开始下一夜。每夜清空后按 `Q` 或 `E`，也可以点击卡片，从两项随机强化中选择一项；共有 20 种强化。
- 守住右侧核心并活过八夜即获胜。第 4 夜出现精英事件，第 8 夜出现 Boss。玩家生命耗尽或核心被摧毁即失败。按 `R` 重开。

敌人沿固定折线道路进攻，包括普通、快速、重甲、远程、精英和 Boss。远程敌人也会攻击炮塔。击杀敌人获得金币；炮塔按设定优先级自动瞄准。夜次越高，敌人数量、生命和速度越高。

## 运行

使用 Godot 4.7 或同系列稳定版导入 `project.godot`，按 F6/F5 运行。命令行可执行 `godot --headless --path . --editor --quit` 验证导入，之后执行 `godot --headless --path . --script res://tests/smoke.gd` 运行逻辑冒烟测试。

## 验证边界

冒烟测试检查夜次编排、敌人类型、命中击退、炮塔管理和 20 种强化的属性变化。画面交互、手感、平衡性及真实图形帧率需要图形环境人工验证。
