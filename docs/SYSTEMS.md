# 系统拆分与修改入口

## 文件边界

| 系统 | 规则／数据 | 业务逻辑 | 接入点 |
| --- | --- | --- | --- |
| 装备品质、多词条、重铸 | `scripts/config/equipment_rules.gd` | `scripts/equipment_system.gd` | `hero_rpg.gd` 保存物品实例，`game.gd` 执行扣款 |
| 命中类词缀效果 | 同上 `AFFIXES` | `scripts/affix_effects.gd` | 基地与营地真实命中后调用 |
| 重铸界面 | 装备配置中的中文名称 | `scripts/equipment_ui.gd` | `game.gd` 转发输入与绘制 |
| 三阶形态 | `scripts/config/evolution_rules.gd` | `scripts/skill_evolution.gd` | 基地／营地施法与 `combat_builds.gd` 读取共享机制配置 |
| 自适应出怪 | 导演脚本中的占比与夜次门槛 | `scripts/enemy_director.gd` | `game.gd.start_wave/update_spawning` |
| 架盾、震荡行为 | 职责脚本中的周期、范围与伤害 | `scripts/enemy_counter.gd` | `build_evolution.gd` 兼容转发，基地与营地共用 |
| 召唤物生命与承伤 | 生命公式及护佑系数 | `scripts/summon_health.gd` | 敌人选目标、近战／敌弹碰撞及召唤更新 |

`game.gd` 保留战场状态和交易编排，`dungeon.gd` 保留营地移动、施法与碰撞入口，`hero_rpg.gd` 保存本局成长与背包。这些入口仍需调用对应系统，不要求把实际碰撞代码复制进规则模块。`build_evolution.gd` 只保留共用范围伤害、连锁反馈及兼容转发，敌人职责、词缀触发与形态规则已有独立文件。

## 装备记录与交易约束

基础物品 ID 保持原目录不变。完整随机记录为 `quality`、`power`、`affixes`、`reforges`：分别表示品质、基础属性倍率、最多四个不重复词缀和已重铸次数。

- `inventory` 与 `inventory_rolls` 必须同索引；`equipment` 与 `equipment_rolls` 必须同槽位。
- `inventory_affixes/equipment_affixes` 只保留首词缀，兼容旧入口；实际属性和触发应读完整记录。不要把首词缀当成物品的全部词条。
- 商品目录自带的稀有度用于基础价格和固有效果，随机品质另外决定基础倍率与词缀数；普通固定商品沿用倍率一和无词缀。
- 增加新数值词缀：先改配置，再在 `EquipmentSystem.apply_stats` 增加属性映射。增加触发词缀：改 `AffixEffects`；复苏在统一击杀入口调用，专注经 `HeroRPG.cooldown_seconds` 生效。
- 生成、重铸不直接扣金币；战场先校验阶段、预算、容量与锁定，再生成结果、写入、扣款。失败校验不能消耗随机源或金币。
- 重铸保留品质、基础倍率和锁定位置。费用为 `15＋5×max(1,词条数)＋5×锁定数＋5×历史次数` 金币。至少留一个未锁定词条，未锁定位置每次实际变化且保持不重复。

## 三阶形态

路线首次锁定后不能改选另一条，但可继续领取本路线二阶、三阶。完成夜数门槛为二／四／六，等级门槛为二／四／七；同时满足才开放 V 面板。

修改解锁门槛看 `NIGHTS/LEVELS`，中文阶段名看 `STAGES`，各阶范围、回响、连锁目标、触发次数、射程与迸发数量看 `MECHANICS`。新增机制类型还需在战场／营地施法或召唤行为中接入，不能只加名称而不结算。

## 自适应出怪边界

每次开波读取上一夜累计实伤差值。普攻与被动／词缀合为一个来源，另有技能、召唤、炮塔。第四夜开始，单一来源占比至少百分之六十才适应；最多给本夜五分之一的普通敌人替换职责，不改怪数、生命、金币、经验，不替换精英或首领。

普攻或炮塔占主导时增加护卫，技能或召唤占主导时增加震荡。召唤主导时震荡可以锁定范围内召唤物的位置。计划开波冻结，不在战斗中读取刚换的装备临时调整；提示常驻战场左上，原始计划保存在矩阵 `director` 字段。

## 召唤物承伤边界

新单位生命为 `30＋3×创建时英雄等级＋4×召唤技能等级` 点。现存单位不会因重复 Q 自动回满血；Q 只补齐数量并按形态刷新寿命。W 恢复每只 `8×W等级` 生命，护佑期间召唤物承伤乘零点七五。

敌人优先攻击已到达的核心；否则可以攻击射程内比英雄更近的存活召唤物。近战要等原有前摇完成且仍在范围内，远程沿锁定方向发射真实弹丸。召唤物可以截获弹丸，但不阻挡道路。震荡对圈内召唤物扣十二生命，已从旧版扣寿命改为真正承伤。

`damage` 只扣生命，不在敌人或弹丸遍历中删单位；`combat_builds.tick` 统一处理生命归零或寿命耗尽。普通召唤物死亡不发金币和经验，献祭形态按阶段产生死亡爆炸／弹丸。换地图直接清除，不触发献祭，也不保留跨地图弹丸。

## 验证入口

- `systems_mechanics.gd`：一千二百个品质样本、十二词缀覆盖、实例交换、锁定重铸、六条路线三阶、自适应冻结与上限、正式近战／弹丸承伤和死亡无奖励。
- `evolution_matrix.gd`：六路线×双英雄×三个种子，以及十二局营地衔接，共四十八局。正常经济购买、重铸和进阶，结算必须三阶且胜利。
- 其余原有矩阵、金币、装备、输入、八夜、副本和胜负测试继续保留。

运行 `tests/run_tests.ps1`，每项独立限时；新代码修改完先检查对应模块，再运行完整回归。完整脚本清单与结果见本轮报告，不能用固定高等级夹具代替正常升级通关证据。
